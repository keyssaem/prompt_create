# 생활 문제 프롬프트 제작소

초등 고학년 학생이 생활 속 문제를 고르고, 직접 확인해 다듬고, 게임 같은 웹앱으로 설계해 **AI 도구에 보낼 프롬프트**를 완성하는 수업 도구입니다.

- 사이트: https://keyssaem.github.io/prompt_create/
- 설치, 로그인, 서버가 필요 없습니다. 입력 내용은 학생 기기의 브라우저(localStorage)에만 저장되고 어디에도 전송되지 않습니다.

## 수업 흐름 (40분 × 5차시)

| 단계 | 차시 | 학생 활동 |
|---|---|---|
| 1. 문제 찾기 | 1차시 | 문제 카드 12개 중 고르거나 직접 찾기, 친구·가족에게 물어보기 |
| 2. 문제 문장 쓰기 | 1~2차시 | 장소·누가·언제·어려움으로 문제 문장 쓰기, 확인한 내용 기록 |
| 3. 앱 설계 | 2~3차시 | 앱 이름, 사용자, 핵심 기능, 게임 구조, 기술 고르기 |
| 4. 프롬프트 다듬기 | 3차시 | 자동 초안을 직접 고치기, 검토 질문 4개, 고친 이유 쓰기 → 복사·.txt 내려받기 |
| 5. 만들고 고치기 | 4·5차시 | AI 도구로 만들기, 친구 테스트, 개선 프롬프트, 발표 카드, 활동지 인쇄 |

AI 도구는 학교에서 허용한 교육용 도구(예: 캔바 AI, 마주온 헬피챗)를 씁니다. 프롬프트는 특정 도구에 맞추지 않았고, 결과를 `index.html` 한 파일로 받도록 짜여 있습니다.

## 파일 구조

```
index.html       화면 뼈대와 선생님용 안내
css/style.css    디자인과 인쇄용 활동지 스타일
js/content.js    문제 카드, 게임 아이디어, 기술 설명, 선택지 문구 ← 내용을 바꿀 때는 이 파일만 고치세요
js/app.js        상태 저장, 화면 그리기, 프롬프트 조립
```

## 내용 고치기

1. GitHub에서 `js/content.js`를 열고 연필(Edit) 버튼을 누릅니다.
2. 문장을 고친 뒤 **Commit changes**를 누르면 1~2분 뒤 사이트에 반영됩니다.
3. 따옴표(`'`)와 쉼표(`,`)를 지우지 않도록 조심하세요.

참고 자료(통계, 기사)를 카드에 넣으려면 `SRC`에 출처를 추가하고, 카드에 `fact`와 `src`를 적으면 됩니다. 자세한 방법은 파일 안 주석에 있습니다.

## 배포 (GitHub Pages)

저장소 **Settings → Pages**에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 정하면 됩니다.
